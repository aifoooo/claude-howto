# API 模块规范

此文件覆盖根目录 CLAUDE.md，对 /src/api/ 下的所有内容生效。

## API 特定规范

### 请求验证
- 使用 Zod 进行 schema 验证
- 始终验证输入
- 返回 400 及验证错误信息
- 包含字段级错误详情

### 认证
- 所有端点需要 JWT 令牌
- 令牌放在 Authorization 请求头
- 令牌 24 小时后过期
- 实现 refresh token 机制

### 响应格式

所有响应必须遵循此结构：

```json
{
  "success": true,
  "data": { /* 实际数据 */ },
  "timestamp": "2025-11-06T10:30:00Z",
  "version": "1.0"
}
```

错误响应：
```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "用户可见的错误消息",
    "details": { /* 字段级错误 */ }
  },
  "timestamp": "2025-11-06T10:30:00Z"
}
```

### 分页
- 使用游标分页（而非偏移量）
- 包含 `hasMore` 布尔值
- 最大页面大小限制为 100
- 默认页面大小：20

### 限流
- 已认证用户：每小时 1000 次请求
- 公开端点：每小时 100 次请求
- 超过限制返回 429
- 包含 retry-after 响应头

### 缓存
- 使用 Redis 进行会话缓存
- 默认缓存时长：5 分钟
- 写操作时使缓存失效
- 使用资源类型标记缓存键
