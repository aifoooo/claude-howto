# 我的开发偏好

## 关于我
- **经验水平**：8 年全栈开发经验
- **偏好语言**：TypeScript、Python
- **沟通风格**：直接，提供示例
- **学习风格**：图表配合代码

## 代码偏好

### 错误处理
我偏好显式的错误处理，使用 try-catch 块和有意义的错误消息。
避免使用通用错误。始终记录错误以便调试。

### 注释
注释用于说明为什么，而不是做什么。代码应该是自解释的。
注释应该解释业务逻辑或不明显的决策。

### 测试
我偏好 TDD（测试驱动开发）。
先写测试，再写实现。
关注行为，而不是实现细节。

### 架构
我偏好模块化、低耦合的设计。
使用依赖注入以提高可测试性。
分离关注点（Controllers、Services、Repositories）。

## 调试偏好
- 使用带前缀的 console.log：`[DEBUG]`
- 包含上下文：函数名、相关变量
- 尽可能使用堆栈跟踪
- 日志始终包含时间戳

## 沟通
- 用图表解释复杂概念
- 先展示具体示例，再解释理论
- 包含前/后代码片段
- 最后总结要点
