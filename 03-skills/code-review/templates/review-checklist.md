# 代码审查检查清单

## 安全检查清单
- [ ] 无硬编码凭据或密钥
- [ ] 所有用户输入的输入验证
- [ ] SQL 注入防护（参数化查询）
- [ ] 状态变更操作的 CSRF 保护
- [ ] 正确转义的 XSS 防护
- [ ] 受保护端点的认证检查
- [ ] 资源的授权检查
- [ ] 安全密码哈希（bcrypt、argon2）
- [ ] 日志中无敏感数据
- [ ] 强制 HTTPS

## 性能检查清单
- [ ] 无 N+1 查询
- [ ] 适当使用索引
- [ ] 有益处的地方实现了缓存
- [ ] 主线程上无阻塞操作
- [ ] 正确使用 async/await
- [ ] 大数据集分页
- [ ] 数据库连接池化
- [ ] 优化正则表达式
- [ ] 无不必要的对象创建
- [ ] 防止内存泄漏

## 质量检查清单
- [ ] 函数 < 50 行
- [ ] 清晰的变量命名
- [ ] 无重复代码
- [ ] 正确的错误处理
- [ ] 注释解释为什么，不是做什么
- [ ] 生产环境无 console.log
- [ ] 类型检查（TypeScript/JSDoc）
- [ ] 遵循 SOLID 原则
- [ ] 正确应用设计模式
- [ ] 自解释代码

## 测试检查清单
- [ ] 编写了单元测试
- [ ] 覆盖了边界情况
- [ ] 测试了错误场景
- [ ] 存在集成测试
- [ ] 覆盖率 > 80%
- [ ] 无不稳定测试
- [ ] Mock 外部依赖
- [ ] 清晰的测试名称
