# 路线图：claude-howto 2026–2027

> 2026年4月 – 2027年3月 · 双层知识库 | 完整计划：`TASKS-20260401.md`

---

## 愿景

将 claude-howto 从一个静态教程仓库转变为一个**活的双受众知识系统**：

- **面向人类** — 基于场景的交互式学习，包含渐进式难度、决策树和专家书签命名的模式
- **面向 AI 代理** — 结构化元数据索引，代理在执行 Claude Code 任务前查询该索引，使此仓库成为基础设施，而不仅仅是内容

目前没有竞争对手将 AI 代理作为主要受众。这是我们的护城河。

## 里程碑

### M1 — 基础设施上线 · 2026年4月底

**交付内容：**
- `scripts/quickstart.sh` — 一键式新手设置（幂等）
- `QUICKSTART.md` — 前15分钟视觉指南
- 所有10个模块的难度徽章 + "What you'll build" 预览
- `WHATS-NEW.md` + 所有模块的版本徽章
- `.github/workflows/staleness-check.yml` — 每周一检查模块30天以上未验证则创建 issue
- 根 `CLAUDE.md` — 项目自身配置作为最佳实践示例
- `scripts/build-agent-index.py` — 生成器，读取所有10个模块 → 输出 `agent-manifest.json` + `AGENT-INDEX.md`
- **06-hooks** — 完整深度更新：5个完整 hook 脚本、决策树、Try It Now、模式
- **08-checkpoints** — 完整深度更新：311 → 800+ 行，3个工作流模板、决策树、模式

**为什么从这里开始：** 基础设施使每个未来阶段都受益。Hooks 和 checkpoints 是最弱的模块，最可能流失新访客。
